# ADR 0004: M1 evidence verification boundary

- Status: Accepted
- Date: 2026-11-20

## Decision

M1 may establish source storage, provenance, quote-location utilities, and reference-integrity foundations. The complete evidence-verification implementation remains in M2 unless the project scope is explicitly revised.

## Consequences

M1 source records and utility foundations must not be described as fully verified evidence or as proof that a source is truthful or representative.
