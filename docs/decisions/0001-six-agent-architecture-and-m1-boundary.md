# ADR 0001: Six-agent architecture and M1 boundary

- Status: Accepted
- Date: 2026-11-20

## Decision

Preserve the six sequential agents specified in Revision 3. M1 implements Agent 1 only. This Phase 1 repository foundation does not implement any agent.

## Consequences

The repository may reserve package structure for later agents, but no later-agent behavior belongs in M1. Agent 1 must collect and store research sources; it must not size markets or analyze competitors.
