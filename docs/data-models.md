# AI-Based Startup Idea Validator

## Data Models Documentation

### 1. Overview

Data models define how information is structured and transferred between different components of the application.

### 2. User Request Model

- Stores the startup idea submitted by the user.
- Contains the idea description.
- May include target audience, location, and budget.
- Validates the input before processing.

### 3. Idea Brief Model

- Stores the analyzed startup idea.
- Contains important information extracted by the Idea Analyzer.
- Provides structured input for the Query Planner.

### 4. Research Query Model

- Stores search queries generated by the Query Planner.
- Organizes queries for market research.
- Provides input to the Search Executor.

### 5. Search Result Model

- Stores information collected through the Tavily Search API.
- Contains relevant web research results.
- Provides collected information to the Evidence Packager.

### 6. Evidence Pack Model

- Stores organized research evidence.
- Removes duplicate sources.
- Prepares structured evidence for further analysis.

### 7. Agent 1 Response Model

- Stores the final output generated by Agent 1.
- Contains the structured research response.
- Sends the result from the backend to the frontend.

### 8. Data Flow

1. User Request is received by the backend.
2. Idea Analyzer creates the Idea Brief.
3. Query Planner generates Research Queries.
4. Search Executor collects Search Results.
5. Evidence Packager creates the Evidence Pack.
6. Agent 1 Runner coordinates the workflow.
7. Agent 1 Response is returned to the frontend.

### 9. Conclusion

Data models help maintain a structured flow of information between different components. They make communication between the backend, agents, and frontend easier to manage.
